# UI 检测计划（UI-AUDIT）

> 原则：**检测项 → 状态 → 验收方法**；每轮至少跑一遍「关键路径」清单；发现问题先定位根因（运行时错误面）再修。
> 状态：✅ 通过 / 🔧 已修待验 / ❌ 失败 / ⏳ 待做。
