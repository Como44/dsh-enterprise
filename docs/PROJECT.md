# PROJECT —— 项目目标与边界（长期不变）

## 目标

> 把 DSH 从一个「个人 Agent Harness」升级为「企业可多人使用、共同沉淀 AI 能力、统一管理权限/资产/成本/外部账号的 AI 工作平台」。

实现形态：**开源 DSH 插件 dsh-enterprise（企业控制层）**，借 Accio Work Business（企业版）作为参考样本，但以 DSH 现实为准并做出更开放、更透明的设计。

## 核心前提：BYO API（自带上游模型）

> 企业**购买上游 API（DeepSeek / OpenAI 兼容 / 其他 Provider），在 DSH 配置**，即可像用 Accio Work Business 一样使用 DSH：
> 无平台积分、无充值、无套餐；用量与成本 = 真实 API 价格 × Tokens，可对账；数据留在本机（自托管）。

## 长期边界

1. **不重造 DSH**：AgentPreset/Skill/会话/凭证/权限/调度/团队等原生能力一律复用，企业层只加「对象关系、可见性、归因、政令视图、预算、审计索引」；
2. **不改坏原模式**：企业模式独立（overlay 载体），插件卸载后 DSH 完全恢复原样；
3. **数据隔离**：企业数据仅 `$DSH_HOME/enterprise/`；DSH 数据只读引用；
4. **成本透明**：用真实 API 价格 + Tokens，不做虚币/充值/账单；
5. **资产显式化**：共享/发布必须显式，禁止静默变更；版本与「当前方法」可查；
6. **不复制品牌**：不抄 Accio logo/插画/图标素材/私有代码/未公开实现；只学产品范式。

## 成功标准（最高层）

- 员工：打开企业工作台 → 知道公司有哪些智能体 → 直接开始工作；
- 管理员：知道谁用了什么、花了多少、产生了什么资产；
- 公司：AI 能力（Agent/Skill/知识）持续沉淀为企业资产，员工离职不流失。
