# MVP —— 第一版范围与验收

> 目标（人话）：先把「企业控制层」跑通 —— 企业空间、成员、资产、用量成本、统一后台。**不追求功能数量，追求一条能走通的主链路：员工创建/找到智能体 → 开始对话 → 公司在用量面板看到他花了多少、用了哪个 Agent、成本多少。**

## P0（MVP 必做）

| # | 模块 | 具体 | 状态 |
|---|---|---|---|
| ① | 企业空间 | 创建企业（种子）+ 企业切换入口 + 企业设置（名称/说明） | ✅ 已实现（MVP 单企业 + 可切换；多企业字段预留） |

## P0 完成标准（每条可验证）

1. **功能**：打开企业工作台 → 创建智能体（五步）→ 绑定预置角色 → 「对话」进入 DSH 会话（真实开会话）；成员增删改；共享切换生效；
2. **数据**：重启 DSH 后成员/资产/设置仍在（企业数据文件独立）；用量从 DSH 会话真实聚合；
3. **权限**：Member 不能改角色/删成员（UI 禁用 + host 校验）；Owner/Admin 可；
4. **成本**：真实会话在用量面板产生正确记录（会话数/回合/Tokens 递增）；
5. **资产**：创建/发布（个人→企业共享）/撤回闭环，状态正确持久化；
6. **异常**：坏预置角色（broken）显示不可用不崩；额度字段缺失降级；数据文件损坏自动重建种子并提示；
7. **UI**：实际打开界面完成上述操作（不做纯代码验收）。

## P1（下一批）

企业知识库（目录索引 + 可见范围）；成本明细（usageCost 接真实价格表 + 时间趋势 + 模型维度）；成员额度（只读展示 + 告警）；推荐资产/企业默认；Connections 只读目录；审计视图（按成员/Agent 过滤会话）；多 Provider/模型映射；资产转移与离职处理箱；Plugin 依赖清单展示。

## P2（远期）

成员额度强制执行（预算规则）；连接完整管理（授权/绑定/Scope）；Agent Team 管理视图；Automation 企业化（谁拥有/谁执行/用谁额度/失败通知）；Channels；精细化权限（部门/资源级）；知识库检索与 Agent 引用；审计导出；Power 规则（连接白名单/供应链治理）。

## 明确不做（本版本）

充值/支付/账单（SaaS 商业模式）；平台代币（i豆）；Agent Hub 市场；静默更新；桌面端复刻；真实多人认证（P2 接网关）；恶意竞争品比对功能。
