# UI-IA —— 界面信息架构

> 原则：**功能等价 + DSH 原生 + 企业管理体验优秀**；学习 Accio 的架构与用户路径，不复制品牌/素材/图标。
> 载体：DSH 内插件（`sidebar.footer.action` 入口 → `shell.overlay` 全屏工作台），DSH 原界面零改动。

## 1. 全局导航（企业工作台侧边栏）

```text
E 企业名（可切换企业，MVP 单企业 + 切换入口）        ← 顶部
├── 总览 Overview            ← 首页：我的智能体 / 最近工作 / 快速开始 / 企业推荐
├── 智能体 Agents            ← 企业 Agent 目录（页签：全部/企业共享/个人）
├── 技能 Skills
├── 企业资产 Assets          ← 统一资产视图（Agent/Skill/Plugin；共享状态筛选）
├── 使用量与成本 Usage & Cost ← 企业总/成员/模型/Agent 用量 + 估算成本 + 额度
├── 连接 Connections         ← P1 只读：外部账号目录与状态
└── 组织 Organization
    ├── 成员 Members
    └── 设置 Settings（企业信息/预算/数据重置/关于）
底部：当前成员卡片 + 退出企业模式
```

参考：Accio 个人版「低门槛前台 + 控制后台」结构 + Business 后台化分组；我们的「组织」组对应其「团队管理」心智。

## 2. 页面规格（MVP）

| 页面 | 组成 | 交互要点 |
|---|---|---|
| Overview | 我的智能体卡组 / 最近工作 / 快速开始 / 企业推荐能力 | 卡片点击→详情；「对话」→ 开 DSH 会话 |
| Agents | 搜索 + 添加智能体 + Banner + 页签 + 卡片网格 + 预置角色区 | 卡片：圆头像/名称/一句说明/角色标签/全宽绿色「对话」；详情 Drawer；**五步创建向导**（选择起点→身份与模型→插件→技能→用户信息，进度条 + 实时预览） |
| Skills | 卡片网格（name/描述/模型可调用/企业共享） | 只读 + 「/name 使用」提示 |
| Assets | 表格（名称/类型/创建者/所属企业/共享/更新时间）+ 类型与共享筛选 | 共享一键切换（个人⇄企业共享）；推荐/P1 |
| Usage & Cost | 统计卡（会话/回合/步骤/LLM 时间/输出 Tokens/估算成本）+ 按成员表 + 按 Agent 表 + 按模型表 + 数据口径说明 | P1 加时间趋势图（simple bars）+ 成员额度列 |
| Members | 表格（成员/邮箱/角色/加入时间）+ 添加成员 Modal | Owner 不可改；移除需确认 |
| Settings | 企业名称/说明/预算（只读）/演示数据重置/关于（数据位置与隔离说明） | 保存即时生效 |

## 3. 视觉语言（借鉴点，不抄袭）

- 借鉴：**行为优先**（绿色主操作：对话/下一步/保存）、信息密度（卡片+表格双表现）、空态引导、步骤式创建（进度条+预览）、页签与筛选分组；
- 不抄：Accio logo/插画/图标素材；我们用自有 SVG 线性图标 + emoji 头像体系 + 自主取色（绿系主色为通用 SaaS 语义，非商标）；
- 深浅色跟随系统（prefers-color-scheme），Web-first。

## 4. 状态与反馈

- 全局：Toasts（成功/错误）、空态文案、加载态；
- 资产卡：共享状态徽标、演示徽标、预置徽标；坏基座（broken preset）显式标"不可用"并给出原因（五道门可见性）；
- 数据口径诚实标注：成员用量为"演示映射"（本机单用户），成本为"最近 40 会话聚合"，未知价格显式 `?`。

## 5. 与 DSH 原生界面的边界

- 会话对话、模型选择、权限审批都留在 DSH 原生界面（企业工作台只做管理面）；
- 企业工作台内只发起动作（开始对话/打开会话/打开工作区），不做聊天复刻——聊天交给 DSH，最大化原生体验。
